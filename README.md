# 🚀 NOQ – Digital Queue Manager (UI/UX Project)

✨ **Say goodbye to waiting in long lines!**  
NOQ is a **digital queue management system** designed to solve campus crowding — mess, laundry, library, or any other queue — with **virtual token-based line skipping**.  

---

## 🎯 Features (Planned + Done)

✅ **Welcome Page UI**  
✅ **Login Page UI**  
⏳ **Dashboard (Coming Soon)**  
⏳ **Virtual Queue Token Interface**  
⏳ **Notifications & Alerts**
